# 文件/文件夹 → 阶段分类规则

按从上到下的优先级匹配。命中即停止。命中不到则归入 `其他/`，并向用户标注 `❓` 待确认。

## 1-售前

### 1-售前/招标文件
- 关键词：`招标`、`招募`、`采购文件`、`甄选`、`询价`、`SHZF`、`zb`、`bidding`
- 示例：`招标文件/`、`xxx招募文件/`、`采购文件/`

### 1-售前/投标文件
- 关键词：`投标`、`应答`、`报名材料`、`资格`、`合作伙伴文件`、`已用印`、`投标案例`、`扫描件`
- 示例：`投标文件/`、`应答材料/`、`合作伙伴文件/`、`报名材料/`

### 1-售前/售前材料
- 关键词：`调研`、`需求`（不含"修改/确认"）、`建设方案`、`技术方案`、`方案梳理`、`技术澄清`、`原始需求`、`项目前期`、`战略协议`、`框架协议`（若属售前阶段）、`专利`、`参考资料`、`案例`（合同案例除外）
- 示例：`调研报告/`、`建设方案/`、`项目前期需求/`、`技术方案书/`、`AI智能体技术澄清/`

## 2-启动

### 2-启动/报价单
- 关键词：`报价`、`报价单`、`报价依据`、`财政证明`、`开票`、`入围服务费`
- 示例：`报价单/`、`报价/`、`9）报价依据/`、`财政证明/`、`开票/`

### 2-启动/合同
- 关键词：`合同`、`协议`（属于已签订）、`补充协议`、`劳务合同`、`框架合同`
- 示例：`合同/`、`人员劳务合同/`、`协议/`

### 2-启动/制作排期
- 关键词：`排期`、`计划`、`schedule`、`开工`（项目计划性质）

### 2-启动/合作确认函
- 关键词：`确认函`、`商务确认`、`中标通知`、`入围`、`合作确认`
- 示例：`商务确认函/`、`开工资料/`（若包含确认/启动文件）

## 3-制作

### 3-制作/需求确认ppt
- 关键词：`需求确认ppt`、`方案ppt`（内部对齐用）、`内部需求`
- 示例：`PPT/`（若是过程ppt）、`ppt/`

### 3-制作/数据需求清单
- 关键词：`数据对接`、`数据需求`、`数据预审核`、`需求整理清单`、`需求清单`、`数据需求清单`
- 示例：`数据对接清单/`、`数据需求清单/`、`需求整理清单/`

### 3-制作/需求确认单
- 关键词：`需求确认单`（自动生成）、`确认单`

### 3-制作/前端低保真
- 关键词：`原型`、`低保真`、`UI`、`示意图`、`草图`、`wireframe`
- 示例：`示意图０６２０/`

## 4-交付

### 4-交付/交付结果
- 关键词：`交付`、`部署文档`、`二开`、`源码`、`代码`、`成品`、`安装包`、`51cloud`
- 示例：`二开部署文档/`、`代码/`、`*.51cloud`

### 4-交付/数据
- 关键词：`数据`、`tif`、`DEM`、`json`、`bmv`、`卫星影像`、`底板`、`POI`、`素材`、`视频`（数据性质）、`模型`
- 示例：`数据/`、`素材/`、`test/`、`test01/`（若为数据测试）、`DEM.tif*`、`*.bmv`、`GridIDArray*.json`

## 5-反馈

### 5-反馈/会议记录
- 关键词：`会议`、`纪要`、`录像`、`会议视频`
- 示例：`会议记录/`、`视频/`（会议性质）

### 5-反馈/需求修改
- 关键词：`需求修改`、`变更`、`解决问题`、`问题清单`、`bug`、`issue`
- 示例：`解决问题清单/`

## 6-收尾

### 6-收尾/验收单
- 关键词：`验收单`、`交付验收`、`终验`、`初验`、`验收报告`
- 示例：`【交付验收单】服贸会.docx`、`【已用印】【交付验收单】xxx.pdf`、`验收单/`、`招商验收材料/`

### 6-收尾/汇报文档
- 关键词：`最终汇报`、`汇报ppt`、`结项`、`交付截图`、`复盘`
- 示例：`最终汇报ppt/`、`交付截图/`

## 其他（需用户确认）

- 名称完全不匹配上述任一关键词
- 名称为乱码（如 `鎶ヤ环鐢氶夋嵁` 这种 GBK→UTF-8 误码）
- 含义模糊的字母/数字命名（如 `51/`、`A1/`、`174023/`、`091911/`）
- 工具/通用资源（如 `CA/`）

## 歧义处理建议

| 情况 | 处理 |
|------|------|
| 同时匹配多个关键词 | 取上面列表中**靠前**的阶段 |
| 子文件夹与父文件夹阶段不一致 | 保持子文件夹整体迁移，不拆散 |
| 视频文件 | 默认放 `4-交付/数据/`，若文件名含"会议/汇报"则放对应阶段 |
| `合同案例/` | 放 `1-售前/售前材料/` 而非 `2-启动/合同/`（属参考案例） |
| `专利/` | 放 `1-售前/售前材料/` |
| 一级 `*.txt`、`*.md` 等散落小文件 | 列表展示给用户，逐项询问；或统一放 `其他/` |
